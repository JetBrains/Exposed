# Samples

This section contains samples for different cases of using Exposed.

- [exposed-ktor](exposed-ktor): Backend application with CRUD (Create, Read, Update, Delete) endpoints, built using Ktor and Exposed.
- [exposed-ktor-r2dbc](exposed-ktor-r2dbc): Backend application built using Ktor, Exposed, and PostgreSQL R2DBC.
- [exposed-jdbc-dao-sample](exposed-jdbc-dao-sample): Backend application built with the JDBC DAO API (`exposed-dao`). A similar `exposed-r2dbc-dao-sample` provides the same app but using the DAO API with an R2DBC driver.
- [exposed-r2dbc-dao-sample](exposed-r2dbc-dao-sample): Backend application built with the R2DBC DAO API (`exposed-dao-r2dbc`). A similar `exposed-jdbc-dao-sample` provides the same app but using the DAO API with a JDBC driver.
- [exposed-spring](exposed-spring): Spring Boot 3 based project with CRUD (Create, Read, Update, Delete) operations.
- [exposed-spring-r2dbc](exposed-spring-r2dbc): Spring Boot 4 based project with suspend CRUD (Create, Read, Update, Delete) operations using PostgreSQL R2DBC.
- [exposed-migration](exposed-migration): Application illustrating how to generate migration scripts with Exposed.
- [exposed-gradle-plugin-sample](exposed-gradle-plugin-sample): Project demonstrating the Exposed Gradle plugin and its `generateMigrations` task.
